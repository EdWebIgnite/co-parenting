# Clickable prototype

A throwaway HTML prototype to settle functionality, look and feel before the proper build. Plain HTML, CSS and JavaScript in one file. No framework, no backend, no Supabase.

## Open it

Double-click `index.html`, or open it in any browser. Use your phone's browser or Chrome dev tools at 360 px wide for the real feel.

## What's in it

- Sign-up with two-step code, consent and mode choice, invite link or solo use
- Today, Calendar, Messages, Money and Kids tabs
- A switch in the dark bar at the top to flip between Cooperative and High-conflict and see what changes
- "Prototype:" buttons that act as the other parent (accept a request, approve an expense)
- Reset in the top bar clears the sample data

All data is invented and stays in the browser (localStorage). Nothing is sent anywhere. School term and holiday dates are samples and need checking before the real build.

This folder is not part of the real app. Do not import from it.
